Контрольное задание 3 содержит три задачи:\
1\) вычислить количество блоков, необходимых для хранения отношения;\
2\) вычислить количество блоков, необходимое для хранения индексного файла;\
3\) вычислить оценку для размера результата реляционного выражения.

Продолжительность: 10 мин.
